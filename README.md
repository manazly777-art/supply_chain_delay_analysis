# Supply Chain Delay Analysis

## 📦 Project Overview

A Power BI and SQL-based analysis of supply chain orders, shipping performance, sales, profitability, and delivery delays. The project focuses on identifying patterns associated with late deliveries and evaluating overall operational performance.

## 🎯 Objective

- Analyze order and delivery performance
- Identify delayed orders and late-delivery patterns
- Compare shipping modes and markets
- Examine sales and profitability
- Analyze shipping time against scheduled shipping time
- Build an interactive dashboard for operational monitoring

## 🛠️ Tools & Skills

- MySQL
- Power BI
- SQL Data Analysis
- Data Cleaning
- Data Transformation
- DAX
- Data Modeling
- KPI Development
- Interactive Dashboard Design

## 📁 Dataset

The dataset contains order-level supply chain information, including:

- Order ID
- Order Date
- Shipping Date
- Days for Shipping (Real)
- Days for Shipment (Scheduled)
- Delivery Status
- Late Delivery Risk
- Sales
- Profit per Order
- Market
- Region
- Country
- Category
- Product
- Shipping Mode
- Customer information

## 📊 Dashboard Analysis

The dashboard focuses on:

- Total Orders
- Sales
- Profit
- Delayed Orders
- Delay Percentage
- Average Shipping Days
- Monthly Sales Trend
- Delayed vs On-Time Orders
- Sales by Market
- Sales by Country
- Shipping Mode analysis

## 🔎 SQL Analysis

SQL was used to query the dataset and answer analytical questions related to:

- Delivery-status distribution
- Delayed versus on-time orders
- Average shipping time
- Shipping performance
- Sales and order patterns
- Market and regional performance


**Domain:** Supply Chain & Operations  
**Tools:** MySQL, Power BI
